# Appointy – MERN Stack Doctor Appointment Booking System

Appointy is a full-stack doctor appointment booking system developed using the MERN Stack.

## Features

- Patient registration and login
- Doctor search and filtering
- Doctor profiles
- Real-time appointment slot availability
- Appointment booking
- Online and offline payment
- Appointment history
- Cancel and reschedule appointments
- Doctor dashboard
- Admin dashboard
- Role-based authentication
- Secure JWT authentication

## Technologies Used

### Frontend
- React.js
- Vite
- React Router
- Axios
- Recharts
- CSS

### Backend
- Node.js
- Express.js
- REST API
- MVC Architecture

### Database
- MongoDB
- Mongoose

### Authentication & Security
- JWT
- bcryptjs
- HTTP Bearer Authentication

### Payment
- Razorpay API
- HMAC-SHA256 signature verification

### Other Tools
- Git & GitHub
- Postman
- Multer
